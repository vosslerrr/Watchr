# [Watchr](https://moviewatchr.vercel.app/)

## Tech Stack
* Source Code: HTML/CSS, Javascript
* Packages:
  * React.js: Used for frontend UI developement and webpage routing
  * Express.js: Used for backend server hosting and RESTful API calls to and from TMDB and MongoDB
* Database: MongoDB
* Hosting: Vercel (Frontend) , AWS EC2 (Backend)
